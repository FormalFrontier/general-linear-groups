# Elementary matrices over arbitrary rings

Import `GeneralLinearGroups.Elementary` for the generators and subgroup,
`GeneralLinearGroups.ElementaryWhitehead` for the Whitehead membership
lemmas, or `GeneralLinearGroups` for the complete public interface.

The native general linear group `Matrix.GeneralLinearGroup ι R` is the unit
group of `Matrix ι ι R`. For finite `ι` with decidable equality and any
`[Ring R]`, `elementaryUnit i j hij c` has matrix value
`1 + Matrix.single i j c`, where `hij : i ≠ j`. Its inverse is the same
construction with coefficient `-c`. Neither coefficients nor their equality
need to be commutative or decidable. The universes of `ι` and `R` are independent.

## Elementary subgroup

`elementarySubgroup ι R` is the subgroup generated by all these units.
`elementaryUnit_mem` provides each generator; `elementary_list_prod_mem`
provides ordered-list product membership without treating `GL ι R` as
commutative. For fixed `(i,j,hij)`, `elementaryUnit_mul_same` gives
`Eᵢⱼ(c) * Eᵢⱼ(d) = Eᵢⱼ(c+d)`; the zero and inverse laws also hold. This follows
from `single i j c * single i j d = 0` for `i ≠ j` and additive
distributivity; it uses no coefficient commutation. Under `[CommRing R]`,
`elementaryUnit_eq_transvection` identifies the unit with mathlib's existing
GL-valued `transvection`, rather than introducing a second commutative notion.

If `ι` has at most one point, no off-diagonal generators exist and
`elementarySubgroup ι R = ⊥`. **This does not imply** `GL ι R` is trivial:
for one index, diagonal units still exist. The API also works for empty
indices and zero rings, without assuming `0 ≠ 1`.

## Block membership

`GeneralLinearGroups.ElementaryWhitehead` imports this library's existing
`GeneralLinearGroups.Whitehead` and reuses its native
`upperUnit`, `lowerUnit`, `swapUnit`, `blockDiagonalUnit` and
`blockDiagonalUnit_eq`, without defining substitutes.

For a matrix `a : Matrix ι ι R`, `upperUnit a = [I,a;0,I]` and
`lowerUnit a = [I,0;-a,I]`. Their elementary membership is proved by
`Matrix.induction_on'`: the zero block gives the identity, sums of blocks
multiply as the corresponding block units, and a one-entry block is exactly
one off-block elementary generator. This works for the empty index type.

The signed swap `swapUnit = [0,-I;I,0]` is the ordered product
`upperUnit (-1) * lowerUnit (-1) * upperUnit (-1)`; the sign is essential.
Finally GLG's existing Whitehead factorization expresses
`blockDiagonalUnit g = [g,0;0,g⁻¹]` as
`upperUnit g * lowerUnit g⁻¹ * upperUnit g * swapUnit`.
The four corresponding membership lemmas place these units in
`elementarySubgroup (ι ⊕ ι) R` for arbitrary rings.

The client `tests/ElementaryClient.lean` exercises a
genuinely noncommutative coefficient ring `Matrix (Fin 2) (Fin 2) ℤ`,
commutative comparison, empty and singleton indices, and `ZMod 1`.
No normality, determinant generation, quotient or stable `K₁` result is claimed.
